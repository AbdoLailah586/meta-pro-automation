# 🚀 منصة ميتا برو — أتمتة التسويق والذكاء الاصطناعي (Meta Pro Marketing Suite)

> المنصة الاحترافية المتكاملة لأتمتة النشر والتسويق الرقمي وإدارة الحملات الإعلانية لصفحات **فيسبوك (Facebook)** وحسابات **إنستغرام (Instagram)** مع مساعد ذكي لصياغة المحتوى مدعوم بنماذج **OpenRouter** المجانية.

---

## ✨ المميزات الرئيسية للمنصة

1. **أتمتة النشر لفيسبوك وإنستغرام (Meta Graph API v21.0)**:
   - نشر فوري بنقرة زر أو جدولة ذكية في التقويم الزمني.
   - دعم كامل للصور، والنصوص التسويقية، والروابط، والهاشتاجات.
   - معاينة حية ومطابقة 100% لكيفية ظهور المنشور على تطبيقي فيسبوك وإنستغرام (Live Mockup).

2. **مساعد الذكاء الاصطناعي المجاني (AI Marketing Assistant)**:
   - دعم نماذج **OpenRouter** المجانية بالكامل (`meta-llama/llama-3-8b-instruct:free`, `google/gemini-2.0-flash-exp:free`, `deepseek/deepseek-r1:free`).
   - قوالب جاهزة لصياغة: صائد الانتباه (Viral Hooks)، عروض وخصومات (Sales & CTAs)، محتوى تعليمي وقيم، وأسئلة تفاعلية.
   - محرك ذكي مدمج يعمل تلقائياً حتى قبل إدخال مفتاح الـ API.

3. **لوحة تحكم وتقويم تفاعلي شامل (Dashboard & Calendar)**:
   - تتبع مؤشرات الأداء: إجمالي الوصول العضوي، التفاعلات، المنشورات المجدولة، ومعدل التحويل.
   - تقويم شهري وأسبوعي لإدارة المنشورات ومتابعة مواعيد إطلاقها.
   - قسم خاص بإدارة الحملات التسويقية ومتابعة ميزانياتها والنتائج التراكمية.

---

## 💻 التشغيل المحلي السريع (Local Development)

1. لتشغيل البرنامج مباشرة بنقرة واحدة على ويندوز، افتح الملف:
   ```cmd
   تشغيل_البرنامج.bat
   ```
2. أو عبر سطر الأوامر (Terminal):
   ```bash
   npm install
   npm run dev
   ```
3. افتح المتصفح على: `http://localhost:3000`

## ☁️ النشر المجاني على Vercel (موصى به - يستغرق دقيقة واحدة)

المشروع مبني بالكامل على **Next.js 14 App Router** ومتوافق بنسبة 100% مع البنية التحتية لمنصة **Vercel** مجاناً:

1. ارفع مجلد المشروع على حسابك في **GitHub**.
2. سجل دخولك على [Vercel.com](https://vercel.com) واضغط **"Add New" -> "Project"**.
3. اختر المستودع الخاص بك (Repository)، ثم اضغط **"Deploy"**.
4. ستقوم Vercel ببناء المشروع تلقائياً وتزويدك برابط مباشر مجاني يعمل مدى الحياة (مثل: `https://meta-pro.vercel.app`).
5. *(اختياري)*: أضف متغيرات البيئة من صفحة Settings في Vercel مثل `OPENROUTER_API_KEY`.

## 🚂 النشر السريع على Railway (بنقرة واحدة)

المشروع يحتوي مسبقاً على ملفات `railway.json` و `Dockerfile`:

1. توجه إلى [Railway.app](https://railway.app).
2. اضغط **"New Project" -> "Deploy from GitHub repo"**.
3. اختر هذا المشروع، وسيقوم Railway باكتشاف الإعدادات وبدء التشغيل كحاوية سحابية تعمل 24/7 مجاناً.

## 🔑 كيفية استخراج رمز الوصول لصفحة فيسبوك (Meta Token)

1. ادخل على [Meta for Developers](https://developers.facebook.com).
2. اضغط **My Apps** ثم أنشئ تطبيقاً جديداً من نوع **Business**.
3. توجه إلى **Tools -> Graph API Explorer**.
4. في خانة **User or Page** اختر **Page Access Token** وحدد صفحتك.
5. أضف الصلاحيات التالية:
   - `pages_manage_posts`
   - `pages_read_engagement`
   - `instagram_basic`
   - `instagram_content_publish`
6. اضغط **Generate Access Token** وانسخه إلى صفحة "ربط Meta" داخل المنصة.
